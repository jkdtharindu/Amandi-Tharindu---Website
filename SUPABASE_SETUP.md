# Supabase Setup Guide

This project uses Supabase (PostgreSQL) for production data persistence. Local development can work with an in-memory fallback.

## Quick Start (Development)

### Option 1: Develop Without Database (In-Memory Mode)
This is the easiest way to get started locally without setting up a database.

```bash
# Just run the dev server—no database setup needed
npm run dev
```

You'll see a warning:
```
Supabase credentials not configured. Using in-memory fallback for development.
```

This is fine! The app will use demo data. Guest login and RSVP flows work end-to-end.

### Option 2: Connect to a Local Postgres Database

```bash
# 1. Install Postgres locally (or use Docker)
# macOS: brew install postgresql
# Ubuntu: sudo apt-get install postgresql

# 2. Create a database
createdb amandi_tharindu

# 3. Set DATABASE_URL in .env
echo 'DATABASE_URL=postgres://localhost:5432/amandi_tharindu' >> .env

# 4. Run migrations
npm run migrate

# 5. Seed demo data
npm run seed:db

# 6. Start the dev server
npm run dev
```

### Option 3: Connect to Supabase (Production-Like)

1. **Create a Supabase project:**
   - Go to [supabase.com](https://supabase.com)
   - Create a new project (choose same region for fastest performance)
   - Wait for the project to initialize

2. **Get your credentials:**
   - In Supabase dashboard, go to **Settings → API**
   - Copy `Project URL` and `anon public key`

3. **Add to .env:**
   ```bash
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_ANON_KEY=eyJhbG...
   # For local migration runner (optional):
   DATABASE_URL=postgresql://postgres:[password]@db.your-project.supabase.co:5432/postgres
   ```

4. **Run migrations (if using DATABASE_URL):**
   ```bash
   npm run migrate
   ```

5. **Seed data:**
   ```bash
   npm run seed:db
   ```

6. **Start dev server:**
   ```bash
   npm run dev
   ```

## Database Schema

The schema is auto-generated by migration files in `migrations/`:

- `001_create_guests.sql` — Guests table with invitation codes and RSVP status
- `002_create_rsvp_responses.sql` — RSVP responses with participant names

Run migrations:
```bash
npm run migrate
```

## Troubleshooting

**"Supabase credentials not configured"**
- This is normal for local development without database. App uses in-memory fallback.
- To enable real database: add `SUPABASE_URL` and `SUPABASE_ANON_KEY` to `.env`

**"DATABASE_URL is required to run migrations"**
- Set `DATABASE_URL` in `.env` to point to your Postgres instance
- Local: `postgres://localhost:5432/amandi_tharindu`
- Supabase: Copy from Supabase dashboard (includes password)

**"Cannot connect to Supabase"**
- Verify URL and keys are correct (watch for spaces/typos)
- Check that Supabase project is active (not paused)
- Verify network access (Supabase may have IP allowlist)
