# How to Send Messages to Guests (Message Center Guide)

A simple guide for the admin who sends the WhatsApp messages.
You do not need any technical skill. Just follow the steps in order.

---

## The short version

1. Open **Messages** in the admin menu.
2. Pick a **Message level** (there are 4, sent in order).
3. Press **Start sending**.
4. For each guest: **Open in WhatsApp** → press **Send** inside WhatsApp → come back → press **✓ Mark as sent**.
5. Repeat until the list is finished. Then do the next level.

**The website never sends anything by itself.** It only opens WhatsApp with the message already typed. *You* press Send, from *your own* WhatsApp. You only see and message your own side's guests.

---

## The 4 message levels

Every guest gets up to four messages, one at a time, in this order.

| Step | Name | What it is | Who it goes to (set for you) |
|---|---|---|---|
| 1 of 4 | **Main invitation** | The invitation with the website link. It has **no code** in it. | Everyone |
| 2 of 4 | **Guest code** | Only the guest's personal RSVP code. | Everyone |
| 3 of 4 | **RSVP reminder** | A gentle nudge to reply. | Only guests who have not replied (**Pending RSVP**) |
| 4 of 4 | **Table number (final)** | Where they will sit. | Only guests who said **Accepted** and are **seated** |

### Why the code is sent in a separate message

The code is the guest's private key to the RSVP page. If the invitation and the code were in one message, and a guest forwarded that message to a friend, the friend could use the code too.

So the invitation (Step 1) never has the code. The code goes alone in Step 2. If someone forwards the invitation, the other person gets the link but **not** the code.

> **Always send Step 1 first, then Step 2.** Do not send the code before the invitation.

## Sending a level to many guests (the Messages page)

### Step A. Choose the level

At the top, open **Message level** and pick the step you want. The **Audience** changes by itself to the usual group for that step. You can change it if you need to.

### Step B. Check who is on the list

Under the dropdowns you will see a line like:

> **24 recipients** · 3 already sent · 2 skipped (no WhatsApp number) · 1 waiting for a table

What it means:

- **recipients** – people you are about to message.
- **already sent** – already ticked for this level, so they are hidden. (This is the "Skip guests already ticked for this level" box. Leave it **ticked** so you never message the same person twice.)
- **skipped (no WhatsApp number)** – these guests have no number saved. Go to **Guests → Edit** and add one. They will then appear.
- **waiting for a table** – Step 4 only. These guests are not seated yet.

**Optional:** use the **Group** dropdown (for example only "Relations") to send to one group at a time.

### Step C. Press "Start sending"

The first guest appears in a box. You will see:

- Their name, code, number and group.
- A small line of ticks, like `✓ Step 1 · Main invitation   ○ Step 2 · Guest code ...`. This shows what they already have.
- The message, already filled in with their name. You can change the words for this one guest if you want.

### Step D. Send it, for each guest

1. Press **Open in WhatsApp**. WhatsApp opens with that guest's number and the message ready.
2. In WhatsApp, press **Send**.
3. Come back to the website and press **✓ Mark as sent**.
   - This puts a tick on the guest and moves you to the next guest automatically.

Other buttons:

- **Skip** – go to the next guest *without* ticking this one (use when you are not ready to message them).
- **Copy message** – copies the text so you can paste it into WhatsApp by hand. Use this if emoji (💍🎊) show up as "�" after pressing Open in WhatsApp.
- **Reset to template** – throws away your edits to this one message.
- **Stop** – ends the run. Your ticks are saved. You can start again any time.

> **Important:** Opening WhatsApp does **not** tick the guest. Only **✓ Mark as sent** does. If you forget to press it, the guest will show up again next time. A tick means "I sent it". It does not prove the guest received it.

If a pop-up is blocked, allow pop-ups for the site in your browser and try again.

When you reach the end you will see **"That is everyone in this group."**

### The progress cards

At the top of the Messages page, four cards show how far each step has got (for example "Step 2 of 4 · Guest code: 60%"). Use them to see what is left.

## Recommended order for the whole wedding

1. **Step 1, Main invitation** → send to everyone. Mark each as sent.
2. **Step 2, Guest code** → send to everyone, **straight after Step 1**. Before you press Open in WhatsApp, look at the ticks line under the guest's name. It should show `✓ Step 1`. If it does not, send them Step 1 first.
   - Tip: both steps list guests in the same A–Z order, so go through them the same way.
3. **Step 3, RSVP reminder** → a week or two later. The Audience is already "Pending RSVP", so people who replied are left out.
4. **Step 4, Table number** → only after seating is **finished** (see below).

## Guests with more than one person (a family or couple)

A "group" invitation (for example **Perera Family**) is **one invitation**, not many:

- It has **one name** (Perera Family).
- It has **one code**.
- It has **one WhatsApp number**.
- Inside it are several named people (for example Nimal, Kamala, Sunil).

So, the right way:

- **Send each step once to the family, not once per person.** Message goes to the one number saved on that invitation. Ask that person to tell the rest of the family.
- Do **not** try to message each member separately. Only the invitation has a number and a code.
- The message will say "Dear Perera Family". That is correct.
- To change which number the family receives messages on: **Guests → Edit** on that invitation → change **WhatsApp number**.
- To see who is in the family: **Guests → Edit** → **People in this party**.

### Step 4 (table) for a family

- The message lists **each person and their own table** automatically, one per line, for example:
  `Nimal – Rose`
  `Kamala – Lotus`
  If they all sit together, the lines show the same table.
- A family only gets the Step 4 message once **at least one** person is seated. If you send it while only some are seated, the message will be missing the others and you will have to send again.
- **So wait until the family shows "All seated"** in the **Seating** column on the Guests page. You can use the **Seating** filter on that page to see who is still partly seated or not seated.
- Families with no seat yet show as **"waiting for a table"** on the Messages page and are left out automatically.

## Sending to just one guest (the Guests page)

Good for a quick message or fixing a mistake.

1. Go to **Guests**.
2. Click the guest's **WhatsApp number** (it is green).
3. A pop-up opens with 4 tabs, one for each step. A **✓** on a tab means it is already ticked.
4. Pick the step, check the message, press **Open in WhatsApp**, and press Send inside WhatsApp.
5. Tick the box **Mark "…" as sent**.

Here you can also **un-tick** a step (untick the box) if you ticked by mistake or need to send it again.

The row of small circles beside each number on the Guests page shows the same thing: a green ✓ is sent, a grey number is not yet sent.

## Changing the wording of a message

1. On the Messages page, pick the level.
2. Open **"Edit the saved template for this level"**.
3. Change the words. Do not delete the tags in square brackets. They are filled in for each guest:

| Tag | Becomes |
|---|---|
| `[Name]` | the guest's name |
| `[Code]` | their code |
| `[Link]` | the website address |
| `[Date]` | the wedding date |
| `[Venue]` | the venue |
| `[TableNumber]` | their table(s) |
| `[Greeting]` | who it is from (The Bride's Family / The Groom's Family) |

4. Check the **Preview**, then press **Save template**. **Reset to default** brings back the original words.

> **Keep `[Code]` out of the Main invitation (Step 1).** That is the whole point of the separate Guest code message.

Changes are shared with your partner's admin account, so tell each other before editing.

### Different invitation wording for different groups (Step 1 only)

The Main invitation can have up to 4 templates, for example a formal one for relatives and a casual one for friends.

1. Press **+ Add template**. It starts as a copy of Template 1.
2. Edit and save it.
3. Under **"Send template 2 to these groups"**, tick the groups that should get it.

A group only gets one template. Groups you have not ticked anywhere get Template 1. The Messages page tells you which template each guest is using.

## If something goes wrong

| Problem | What to do |
|---|---|
| A guest is missing from the list | They may have no WhatsApp number (check the "skipped" count), may be already ticked, or the Audience/Group filter may be hiding them. Try Audience = **Everyone**, Group = **All groups**. |
| I sent it but forgot to press Mark as sent | Find the guest on the **Guests** page, click their number, and tick the step. Or leave it: they will show again on the next run, and you can just Skip or Mark. Do not send twice. |
| I ticked someone by mistake | **Guests** page → click their number → untick that step. |
| WhatsApp does not open | Allow pop-ups for this site. Nothing was saved. Try again. |
| Emoji look like "�" | Use **Copy message** and paste into WhatsApp. |
| "No usable WhatsApp number" | The number is wrong or too short. Fix it in **Guests → Edit**. Sri Lankan numbers like 071 234 5678 are fine. |
| I sent the code before the invitation | It is okay. Just send Step 1 afterwards and tick it. The order matters for safety, not for the website working. |
| Page says Unauthorized | Sign in again at `/admin`. |

## Golden rules

1. Step 1 first, then Step 2 right after.
2. Send once per invitation, not once per person.
3. Always press **Send** in WhatsApp, then **✓ Mark as sent**.
4. Do not send Step 4 until the family is fully seated.
5. Never post a guest's code in a group chat.
