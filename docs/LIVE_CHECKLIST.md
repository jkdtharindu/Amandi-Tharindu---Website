# Live Click-Through Checklist

Site: https://tharinduamandi.vercel.app
Do this on a real phone first, then on a computer. Tick each line. Write down anything odd.

## Guest side (use a test invitation code, not a real guest's)
- [ ] Gate page opens. A wrong code shows "We couldn't find that code" (checked 2026-11-03, works).
- [ ] A right code opens the invitation.
- [ ] RSVP: accept, then change to decline, then accept again. Status updates each time.
- [ ] Add a new person to the party. It shows as waiting for approval.
- [ ] Seated guest asks to decline. The request shows as sent.
- [ ] Table number shows next to each seated person ("Table N - Name") — Action 89, unmerged/unverified.
- [ ] Add to calendar downloads a file that opens in the phone calendar.
- [ ] Home page: every section loads, photos show, countdown is right (Sri Lanka time).
- [ ] Log out and back in. The Invitation button shows the code box again.

## Admin side
- [ ] Admin login works.
- [ ] Dashboard numbers match the guest list.
- [ ] The RSVP from the guest test above appears here.
- [ ] Approve and reject the test "add a person" request.
- [ ] Decline requests panel and the menu count badge update.
- [ ] Table arrangement: seat a person, unseat them, export.
- [ ] Messages: preview a WhatsApp link, check [TableNumber] fills in.
- [ ] Theme / Site wording change shows on the guest home page after reload.

## Clean up after
- [ ] Delete or reset the test guest.
