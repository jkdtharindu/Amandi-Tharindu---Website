# Product

One file per style in `styles/`, named `STYLECODE_name.md` (example: `F-001_tailored-blazer.md`). Use the template below.

Sample flow: Concept → Tech pack → Proto sample → Fit approval → Revisions → PP sample → Bulk approval. Never skip a step without a recorded reason.
