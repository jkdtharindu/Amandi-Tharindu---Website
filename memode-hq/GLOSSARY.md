# Glossary

One meaning per term. If a word means two things, split it. Add terms as they appear.

| Term | Meaning |
|---|---|
| MEMODE | The brand and the business |
| MEMODE FORM | Proposed division: office wear, tailored, smart fashion (not approved) |
| MEMODE EVERYDAY | Proposed division: casual, denim, shirts, polos, everyday dresses (not approved) |
| MEMODE LIVING | Proposed division: lifestyle apparel, accessories (not approved) |
| Accessible luxury | Premium look and quality at a price a wide set of customers can reach |
| Brand-led hybrid ecosystem | MEMODE owns brand, product design, sourcing and customer; partners make the clothes |
| MVC (minimum viable collection) | The smallest first range that can test real demand |
| Tech pack | Document with everything a factory needs to make a style (drawings, measurements, fabric, trims) |
| Spec / size spec | Measurements for each size |
| Proto / fit sample | First sample to check design and fit |
| PP sample | Pre-production sample, approved before bulk |
| MOQ | Minimum order quantity a supplier accepts |
| Lead time | Days from order to delivery |
| FOB / landed cost | Factory price / total cost delivered to our warehouse |
| Gross margin | (Selling price − product cost) ÷ selling price |
| Break-even | Sales needed to cover all costs |
| Working capital | Cash needed to run day to day (stock, supplier deposits, wages) |
| Planned vs actual | Planned = target. Actual = what really happened. Never mix them |
| FACT / ESTIMATE / ASSUMPTION / FORECAST | Evidence labels. See `CLAUDE.md` |
| Gate | A formal approval point at the end of a phase |
| HITL | Human in the loop. Claude stops and asks the founder |
