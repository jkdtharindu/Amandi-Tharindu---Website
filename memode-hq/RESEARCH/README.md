# Research

One file per topic: `YYYY-MM-DD_topic.md`. No research is done yet.

## Rules
- Every note has: question, date, sources (links), findings, limitations.
- Label claims FACT / ESTIMATE / ASSUMPTION. Never invent market size, demand or prices.
- Prefer current sources. Re-check anything older than 6 months before relying on it.
- Anything that changes a plan goes into `ASSUMPTIONS.md` or `DECISIONS.md`.
