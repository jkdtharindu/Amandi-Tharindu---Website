# MEMODE HQ

A markdown "business operating system" for building MEMODE, a contemporary premium fashion brand (Sri Lanka first, international later). Version 0.1, created 2026-11-22.

## How to use it
1. Start a session: paste `STARTUP_PROMPT.md`.
2. Work. Use the trigger phrases in `CLAUDE.md` (Grill me, Project update, Update the md files, Gate check, Roast/Toast me, Cost check).
3. End a session: paste `SESSION_END_PROMPT.md`.
4. Once a week, spend 15 minutes on `TASKS.md`, `TIMELINE.md` and `RISKS.md`.

## Files
| File | Job |
|---|---|
| `CLAUDE.md` | Rules and trigger phrases |
| `STRATEGY.md` | Approved directions only |
| `DECISIONS.md` | Decision log |
| `ASSUMPTIONS.md` | Unproven beliefs |
| `TIMELINE.md` | Master schedule and gates |
| `TASKS.md` | This week's top actions |
| `HITL.md` | When Claude must stop and ask |
| `RISKS.md` | Risk register |
| `GLOSSARY.md` | Terms |
| `GRILL_ME.md` | Interview routine and question banks |
| `VIBE_CHECKS.md` | Roast and toast |
| `UPDATE_ME.md` | Doc sync and project update |
| `HISTORY.md` | Short summary of what has been built (detail is in the real files) |
| `ARCHIVE/` | Old or finished material, moved out to keep files small |
| `FINANCE/` `PRODUCT/` `SUPPLIERS/` `RESEARCH/` `REPORTS/` | Work files |

## Golden rules
- One home for every fact. No duplicate copies.
- Proposed is not approved. Recommendation is not decision.
- Never invent numbers or dates. Write TBD.
- The founder decides.
