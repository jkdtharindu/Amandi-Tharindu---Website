# Archive

Finished or old material lives here so the main files stay small. Claude does not read this folder unless asked or needed.

## When to move something here
- A decision, task or history line is older than 3 months.
- A phase is complete and its working notes are no longer needed day to day.
- A file passes its size limit (see `CLAUDE.md`).

## How
1. Move the old text to `ARCHIVE/<NAME>_<YYYY>.md` (example: `DECISIONS_2026.md`).
2. Leave one line in the main file: `Older entries: see ARCHIVE/DECISIONS_2026.md`.
3. Never delete decisions. Archive them.
